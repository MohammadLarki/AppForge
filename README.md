# AppForge

A lightweight Linux application installer that automatically installs `.tar.gz`, `.AppImage`, and `.deb` applications, creates desktop launchers, and configures application icons.

## Vision

AppForge aims to turn portable Linux application archives into properly integrated desktop applications with minimal user interaction.

## Current status

Early development — the application detector is the first building block of the installer engine.

## Planned support

- `.tar.gz` portable applications
- AppImage applications
- Debian `.deb` packages
- Desktop launcher generation
- Automatic icon discovery and extraction
- Electron/Chromium sandbox configuration
- Uninstallation and application management
